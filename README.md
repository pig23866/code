### 2. 期中考實作與題庫模組 (`期中考/`)

每個題目皆針對不同邏輯與架構進行強化訓練，包含安全輸入防呆機制：

* **`01.cpp` - 學生成績統計與及格判定系統**
  * 輸入 1~30 位學生人數與個別成績，防呆驗證輸入邊界。
  * 逐一評定及格（$\ge 60$）與不及格狀態，並計算及格率。
* **`02.cpp` - 飲品販賣機點餐與結帳系統**
  * 選單品項：水 ($20)、茶 ($30)、咖啡 ($45)。
  * 支援連續點餐累計品項與數量，結帳時輸出清單明細與總金額。
* **`03.cpp` - 校園停車場車位管理系統**
  * 函式模組化設計：`countOccupied()`、`countAvailable()`、`calculateUsage()`。
  * 停車場使用率狀態自動評定（Full / Almost Full / Spaces Available）並列印剩餘空位編號。
* **`04.cpp` - 軍校體能測驗評分系統**
  * 多項目標準級距換算函式：伏地挺身、仰臥起坐、3000 公尺跑步秒數換算。
  * 格式化輸出各項得分與三項總平均成績。
* **`11.cpp` - 電影院票價分類與查詢系統**
  * 依年齡區間智慧判別票種（免費票、兒童票、全票、敬老票）與票價。
* **`22.cpp` - 個人目標存款追蹤與計算系統**
  * 支援小數金額的每日目標儲蓄計算，自動結算達成天數與累積總儲蓄額。
* **`33.cpp` - 密碼安全性強度檢測系統**
  * 走訪字元陣列檢測字串長度、大寫字母 (`A~Z`) 與數字 (`0~9`)，判定密碼強度。
* **`44.cpp` - 商品庫存管理與補貨清單試算系統**
  * 函式計算總庫存、最低庫存與低庫存商品總數。
  * 自動產生補貨清單（庫存低於 10 件自動補足至 20 件），顯示品項與應補數量。

## 🧠 學習核心觀念與技巧

* **輸入驗證與防呆 (Defensive Input Handling)**：
  * 利用 `cin.fail()`、`cin.clear()`、`cin.ignore()` 清除輸入緩衝區，預防無窮迴圈。
  * 利用 `stringstream` 與 `getline` 處理行輸入與格式轉換。
* **流程與結構化控制**：
  * `while`、`do-while`、`for` 迴圈搭配 `switch` 建立功能選單。
  * 陣列走訪、邊界檢查與指標計數回溯。
* **函式模組化 (Modular Programming)**：
  * 將計算統計、狀態判斷與輸入處理拆分為獨立函式，提高程式碼可讀性與重用性。
