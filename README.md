### 2. 期中考實作與題庫模組 (`期中考/`)

分為「**C++ 模擬考題庫** (`01.cpp` ~ `04.cpp`)」與「**C++ 模擬考題庫_2（考試簡化版）** (`11.cpp` ~ `44.cpp`)」兩組題庫：

#### 📘 C++ 模擬考題庫（完整驗證版）

* **`01.cpp` - 第一題：學生考試成績判定系統**
  * 建立固定容量為 30 的成績陣列 `score[30]`，讀取並驗證學生總人數（`0~30` 人，允許 0 人）與各人成績（`0~100` 分）。
  * 以 `>= 60` 分判定及格（`pass`）或不及格（`fail`），依序輸出各人成績、及格判定及總及格/不及格人數（處理 EOF 與 `numeric_limits` 緩衝區清除）。
* **`02.cpp` - 第二題：校園販賣機結帳系統**
  * 顯示一次商品選單：(1) Water: 20元、(2) Tea: 30元、(3) Coffee: 45元、(0) Checkout。
  * 使用 `do ... while` 重複購物並驗證選項（`0~3`），選擇 `0` 時透過三個獨立的 `if` 列出所有已購商品數量與小計（若未購買則顯示提示）及總計金額。
* **`03.cpp` - 第三題：校園停車場車位管理系統**
  * 輸入車位總數 `N`（`1~30`）與各車位狀態（`0` = Available 可使用、`1` = Occupied 已占用），搭配 `readInt()`（`getline` + `istringstream`）嚴格驗證每行一個整數。
  * 實作 `countOccupied()`、`countAvailable()`、`calculateUsage()`，依使用率判定狀態（100% `Parking Full` / 80%~未滿100% `Almost Full` / 未滿80% `Spaces Available`），並列出所有可用車位編號。
* **`04.cpp` - 第四題：軍校體能測驗評分系統**
  * 以三個容量 30 的一維陣列分別保存 `1~30` 位學生的伏地挺身次數、仰臥起坐次數與 3000 公尺跑步秒數原始成績。
  * 實作 `scorePushup()`、`scoreSitUp()`（$\ge 60 \rightarrow 100$、$45\sim59 \rightarrow 80$、$30\sim44 \rightarrow 60$、$<30 \rightarrow 0$）、`scoreRunning()`（$\le 750 \rightarrow 100$、$751\sim900 \rightarrow 80$、$901\sim1080 \rightarrow 60$、$>1080 \rightarrow 0$）及 `calculateTatal()` 計算三項算術平均總分（小數點後兩位）。

#### 📗 C++ 模擬考題庫_2（考試限制與簡化版）
> **考試簡化原則**：針對考場時間與語法限制，移除 `<limits>` 與 `<vector>`，統一改用簡短可執行的 `cin.ignore(1000, '\n');` 處理輸入錯誤。

* **`11.cpp` - 題目一：票價判別系統**
  * 持續讀取並驗證整數年齡（`0~100` 歲），依年齡區間判別四種電影票種與票價：0~5歲 `Free Ticket` ($0)、6~17歲 `Child Ticket` ($150)、18~64歲 `Adult Ticket` ($300)、65~100歲 `Senior Ticket` ($150)。
* **`22.cpp` - 題目二：存錢目標系統**
  * 以 `double` 儲存存錢目標與每日存款（支援小數），驗證目標與當日存款皆須 `> 0`（無效輸入輸出 `Invalid Amount` 且以 `continue` 跳過不計入天數），達標後輸出有效存款天數與累計總額。
* **`33.cpp` - 題目三：密碼安全性系統**
  * 使用 `char password[50]` 搭配 `setw(50)` 讀取密碼（最多 49 字元，保留 `'\0'`），以 `for` 迴圈逐字計算長度並檢查大寫字母（`'A'~'Z'`）與數字（`'0'~'9'`）；同時滿足「長度 $\ge 8$、含大寫、含數字」三項條件才判定為 `Strong Password`。
* **`44.cpp` - 題目四：倉庫庫存管理與補貨系統**
  * 輸入商品種類數 `n`（`1~30`）與各項非負庫存量 `stock[30]`，實作 `calculateTotal()`（總庫存）、`countLowStock()`（庫存 `< 10` 的商品種類數）、`findLowestStock()`（最低庫存量）及 `calculateRestock()`（庫存 `< 10` 時補足至 20 件），輸出補貨清單與總補貨量。

## 🧠 學習核心觀念與技巧

* **輸入驗證與防呆 (Defensive Input Handling)**：
  * 利用 `cin.fail()`、`cin.clear()`、`cin.ignore()` 清除輸入緩衝區，預防無窮迴圈。
  * 利用 `stringstream` 與 `getline` 處理行輸入與格式轉換。
* **流程與結構化控制**：
  * `while`、`do-while`、`for` 迴圈搭配 `switch` 建立功能選單。
  * 陣列走訪、邊界檢查與指標計數回溯。
* **函式模組化 (Modular Programming)**：
  * 將計算統計、狀態判斷與輸入處理拆分為獨立函式，提高程式碼可讀性與重用性。
